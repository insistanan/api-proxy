# 风格词库

用户点到编号、中文名、英文名或下方别名时，从对应词条选择适用的视觉特征，按提示词语种自然表达，不整串复制。词库不能覆盖用户明确的主体、构图、配色、背景或禁止项；未点名时不强行套用本表。

将特征放回 5S 共同判断：笔触、材质和着色用于 Style；视角用于 Shot；光照效果用于 Scene lighting。配色等倾向只有适合当前要求时才采用。不得因为风格名额外添加人物、街道、招牌、机械、植物、品牌字样或图内文案；需要这些元素时以用户要求为依据。

混合风格时说明各自作用，例如「水彩的颜色晕染结合版画的交叉排线」，不叠加彼此冲突的整套预设。
