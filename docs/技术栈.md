# 技术栈总览（tech-stack）

依赖与工具链一览。升级依赖或排查版本问题时先读本文。当前版本：v3.3.0（见 `VERSION`）。

## 总体形态

- 单 Go module：`github.com/BenedictKing/api-proxy`（Go 1.25），无 go workspace
- 单二进制部署：Vue 3 前端构建产物经 `go:embed` 嵌入 Go 后端，一个可执行文件同时提供代理 API（`/v1`、`/v1beta`）与管理界面（`/api` + 静态页面），默认端口 3000
- 历史：v1.x 为 TypeScript 实现，v2.0.0 起用 Go 重写（见 [历史说明.md](历史说明.md)）

## 后端（backend-go/）

| 类别 | 选型 | 说明 |
|---|---|---|
| 语言 | Go 1.25 | `CGO_ENABLED=0` 纯静态构建 |
| Web 框架 | gin v1.10.0 | 唯一 HTTP 框架 |
| 数据库 | modernc.org/sqlite v1.34.4 | 纯 Go SQLite（无 CGO）；WAL 模式、`SetMaxOpenConns(1)`、手写 SQL、无 ORM、无 migration 框架 |
| JSON 操作 | tidwall/gjson + sjson | 避免反复 unmarshal 大 JSON |
| 配置 | fsnotify + godotenv + pelletier/go-toml + yaml.v3 | config.json 热重载（debounce + sha256 摘要比较） |
| 压缩 | klauspost/compress + andybalholm/brotli | 上游响应多算法解压 |
| SSE | 手写（`utils/sse.go`、`handlers/streams`） | 无 websocket、无 SSE 库依赖 |
| 测试 | stretchr/testify + 原生 testing | 117 个 _test.go，含特性测试与静态依赖断言测试 |

## 前端（frontend/）

| 类别 | 选型 |
|---|---|
| 框架 | Vue 3（^3.5）+ TypeScript 5.9（strict） |
| 构建 | Vite 7 + @vitejs/plugin-vue + vite-plugin-vuetify；类型检查 vue-tsc；测试 Vitest 4 |
| UI | Vuetify 3（全量注册）+ @mdi/js 按需 SVG 图标 + SCSS（sass-embedded） |
| 状态 | Pinia 3 + pinia-plugin-persistedstate（localStorage） |
| 路由 | vue-router 4（History 模式、全懒加载） |
| HTTP | 原生 fetch 封装（无 axios），SSE 用 fetch 流读取 |
| 图表/拖拽 | apexcharts 5 + vue3-apexcharts / vuedraggable |
| 包管理 | bun（bun.lock）为主，package-lock.json 并存 |

## 关键运行时组件（后端 internal/ 摘要）

| 组件 | 职责 |
|---|---|
| `handlers/proxycore` | 五协议共享编排骨架 `RunProxyRequest`，协议差异经 `ProtocolSpec` 注入 |
| `converters` | OpenAI/Gemini/Responses ↔ Claude 协议转换（约 10k 行，最大包之一） |
| `providers` | Provider 接口 + openai/gemini/claude/responses 四实现 |
| `scheduler` | ChannelScheduler 多渠道调度 + ChannelPermit 许可句柄 |
| `circuit` / `ratelimit` / `urlhealth` | 渠道级三态熔断 / 滑动窗口限流与平滑排队 / 多 BaseURL 健康管理 |
| `sensitive` / `llmgate` / `handlers/hooks` | 敏感数据检测与可逆脱敏 / 危险命令 AI 闸门 / 内容安全三阶段钩子管线 |
| `session` / `conversation` / `metrics` | Responses 会话与 Trace/BaseURL 亲和 / 对话注册表 / 按 ChannelKind 指标与 SQLite 持久化 |
| `eval` / `assistant` / `skills` | 渠道评测工作台 / AI 配置助手 / Agent Skill 目录管理 |
| `config` / `httpclient` / `proxy` / `atomicfile` | 配置热重载 / 网络发送唯一出口 / 框架无关编排核心 / 原子写原语 |

完整架构与请求流转见 [架构说明.md](架构说明.md)。
