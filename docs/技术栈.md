# 技术栈总览（Tech Stack）

本文档汇总列出 **api-proxy** 的核心技术选型、主要第三方依赖以及工具链版本。在进行依赖升级、排查平台兼容性或评估引入新组件时可供查阅。当前版本号见根目录的 [VERSION](../VERSION)。

---

## 1. 总体工程架构

- **工程形态**：单一 Go Module（`github.com/insistanan/api-proxy`），无复杂 go workspace，便于跨平台交叉编译。
- **发布产物**：Vue 3 前端生产构建产物通过 `go:embed` 技术内嵌到 Go 后端，形成单一独立可执行文件，开箱即用。
- **端口体系**：单端口（默认 3000）整合，同一端口分流代理接口（`/v1/*`、`/v1beta/*`）、管理接口（`/api/*`）与前端静态单页应用。

---

## 2. 后端技术栈（backend-go/）

| 层次/模块 | 选型 | 版本/说明 |
|---|---|---|
| **编程语言** | Go | 最低 1.26.0，锁定工具链 1.26.10。`CGO_ENABLED=0` 静态编译，无 libc 动态链接依赖 |
| **HTTP 框架** | Gin | 提供路由编排与中间件管理，无 WebSocket 需求 |
| **持久化引擎** | modernc.org/sqlite | 纯 Go 原生实现的 SQLite，无需 CGO 编译器；全面开启 WAL 模式；手写精简 SQL，无臃肿 ORM |
| **高性能 JSON** | tidwall/gjson + sjson | 避免对大模型长上下文反复做全量序列化，直接在字节切片上高性能检索与修改 |
| **配置与热重载** | fsnotify + godotenv | 监听 `config.json` 磁盘变更，辅以 100ms 防抖与 SHA-256 校验，实现零停机热更新 |
| **响应解压缩** | klauspost/compress + brotli | 兼容上游服务多样化的 gzip/brotli/zstd 压缩编码 |
| **流式事件处理** | 自研 SSE 解析与转发状态机 | 针对 Claude / OpenAI / Gemini 流式协议手写高效状态机，支持断连即停与实时脱敏还原 |
| **测试套件** | testify + 原生 testing | 包含契约测试、并发准入与资源泄漏回归测试，以及依赖方向静态断言 |

---

## 3. 前端技术栈（frontend/）

| 层次/模块 | 选型 | 说明 |
|---|---|---|
| **核心框架** | Vue 3 (^3.5) | Composition API，响应式驱动 |
| **开发语言** | TypeScript 5.9 | 开启严格模式（strict: true），完整类型安全 |
| **构建与脚手架** | Vite 7 | 极速冷启动与热模块替换（HMR），集成 vue-tsc 类型检查 |
| **UI 组件库** | Vuetify 3 | 采用自定义双主题（“砚与铜”配色），结合 `@mdi/js` 实现按需静态引入 SVG 图标 |
| **全局状态管理** | Pinia 3 | 结合 `pinia-plugin-persistedstate` 实现认证凭证与偏好配置本地持久化 |
| **前端路由** | vue-router 4 | History 模式，所有视图页面全量路由级懒加载 |
| **网络请求** | 原生 fetch 封装 | 统一于 `services/http.ts` 处理鉴权、错误格式化与 Committed 状态拦截；流式由 `utils/sse.ts` 承接 |
| **图表展示** | ApexCharts 5 + vue3-apexcharts | 承载渠道健康度、调用成功率、上下文趋势与 TPS/首字延迟的统计展现 |
| **包管理工具** | npm / Bun | 本地兼容 Bun (1.4.4) 与 npm (Node 24.16.0)；仓库同步维护 `bun.lock` 与 `package-lock.json` |

## 4. 关键运行时组件（backend-go/internal/ 9 大模块）

| 领域模块 | 核心职责 |
|---|---|
| `handlers/` | 协议端点接入与统一流水线：`proxycore` 编排五大编排端点，管理组端点与原样透传端点 |
| `orchestration/` | 调度与稳定性控制：`scheduler` 选渠与许可、`circuit` 三态熔断、`upstreamcontrol` 物理凭据共享准入、`urlhealth` |
| `protocol/` | 协议抽象与转换：`converters` 跨协议转换、`providers` 抽象接口与四大具体上游实现 |
| `safety/` | 安全风控：`sensitive` 敏感数据检测与 AES-256-GCM 可逆脱敏、`llmgate` 危险命令大模型闸门 |
| `dialogue/` | 会话与上下文：`session` 会话与 BaseURL 亲和性、`conversation` 上下文注册表与缓存 |
| `storage/` | 持久化与调用观测：`logger` 读写分离日志落盘、调用聚合（Call Query）、上下文快照（Context Snapshot）与 `metrics` |
| `admin/` | 管理支撑：`assistant` 配置助手、`channelcrud` 协议无关渠道增删改查、`modelcatalog` 模型目录 |
| `infra/` | 基础设施：`config` 配置热重载、`httpclient` 推理请求发送出口、`middleware` 中间件 |
| `eval/` | 渠道与探针评估 |
