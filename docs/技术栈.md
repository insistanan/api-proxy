# 技术栈

前端依赖范围由 `package.json` 声明，实际安装版本由对应包管理器的锁文件确定。应用版本见 `VERSION`。[前端依赖](../frontend/package.json) · [npm 锁文件](../frontend/package-lock.json) · [Bun 锁文件](../frontend/bun.lock) · [应用版本](../VERSION)

## 工具链

| 工具 | 版本来源 |
|---|---|
| Go | [backend-go/go.mod](../backend-go/go.mod) 中的 `go` 与 `toolchain` |
| Node.js | [.node-version](../.node-version) |
| Bun | [.bun-version](../.bun-version)，供发布流程和可选的本地前端安装使用 |
| Air | [后端 Makefile](../backend-go/Makefile) 中的 `AIR_VERSION` |

## 后端

| 选型 | 用途 |
|---|---|
| Go + Gin | 单 module，HTTP 路由与中间件；发布使用 CGO_ENABLED=0 |
| modernc.org/sqlite + database/sql | 纯 Go SQLite、原生 SQL 与 WAL；日志库分开读写连接 |
| gjson / sjson | JSON 查询与局部修改 |
| fsnotify / godotenv | 配置监听与环境变量 |
| klauspost/compress / brotli | 上游响应解压 |
| lm-detector Go SDK（lmfpd，MIT） | 数字挑战生成与本地指纹评分；项目下载层按网络设置获取并校验参考数据，再交给 SDK 加载 |
| 内部 SSE 解析器 | 协议事件转换、断连取消、流式脱敏还原 |
| testing / testify | 单测、协议与资源生命周期回归 |

## 前端

| 选型 | 用途 |
|---|---|
| Vue 3 / TypeScript 5.9 / Vite 7 | Composition API、strict 类型检查与构建 |
| Tailwind CSS 4 / @tailwindcss/vite | 管理台样式、编译和语义主题令牌 |
| Reka UI / @mdi/js | 无样式交互原语及按需 SVG 图标，基础组件源码由项目维护 |
| Pinia 3 / persistedstate | 全局状态、认证与偏好持久化 |
| vue-router 4 | History 路由与页面懒加载 |
| fetch / 内部 SSE 工具 | 管理请求、认证代次取消、完整 SSE 事件读取 |
| Canvas 2D | 个人森林地图、树木与海图绘制，不依赖三维引擎 |
| ApexCharts 5 / vue3-apexcharts | 渠道与上下文统计图表 |
| Vitest / ESLint / vue-tsc | 单测、零警告检查、类型检查 |

本地 `make` 和提交门禁通过 npm 执行前端命令。发布工作流使用 Bun 安装和构建前端，修改依赖时需同步两份锁文件。具体命令见 [开发说明](开发说明.md)。
