## 功能主线（跨版本）

- **评测工作台（已移除）**：从渠道评测工作台（ceae1c8）开始，经历多轮增强，最终在 v3.3.11 中移除页面、接口和后台逻辑。
- **内容安全**：先加入工具名白名单（f42f562）和 bodyfilter 私有参数递归过滤（916f3b9），随后实现可逆脱敏与 SSE 流式还原（768df8c）。后续改动主要减少误报（71e83e3），并支持拦截日志按会话分组、按需加载（b7761b5）。
- **智能代理功能密集期**（2026-09 初）：Prompt Cache 智能断点注入（6e70d7e）、Thinking 参数整流器（b23fb81）、mediasanitizer 模态降级（414364f）、Copilot 优化器（2f8ba1c）、渠道级三态熔断器（004980a，参照 cc-switch）、2xx 错误信封检测 + 流式 prime-then-commit（e44a1fc）、多算法解压缩（310272c）、思考模型跨协议映射 + 首字延迟/TPS 度量（44aada2）、流式缓冲池化 + 429 平滑排队（14507f4）
- **日志存储**：运行日志与请求正文迁入 SQLite，并提供 CLI 查询（6ffcfe2），之后增加系统日志查询接口（96aec60）。

## v3.3.0（2026-09-14）

功能：

- 危险命令 AI 闸门 + AI 配置助手 + llmgate 分组模型路由
- 工具版本检测提醒、拦截记录命中片段
- 安全修复：WebAuthMiddleware 扩展名绕过（7e0b11b）

架构优化首轮 **R1–R6**（docs/architecture-optimization-plan.md 设计稿，旧文档已删，编号保留在代码注释中）：

| 轮次 | 内容 |
|---|---|
| R1–R2 | 网络发送唯一出口 `internal/infra/httpclient`；无框架请求编排 `internal/orchestration/proxy`（静态依赖断言守卫） |
| R3 | 配置重载只发布完整候选快照（前端对应 ApiError.committed 语义） |
| R4 | 渠道许可句柄 `scheduler.ChannelPermit`（R4-b 编号见代码注释） |
| R5 | main.go 拆分 app_lifecycle / app_routes；前端状态收敛到 composables（方案 8.1，be1f23c） |
| R6 | 构建门禁对齐（Go 版本声明对齐 go.mod、ESLint 接入门禁）；修正性能画像误导日志 |

同版本重要变更：

- **移除定价模块**（a4fef41）：渠道自行报价缺乏可信依据，维护成本高于收益，因此移除了该模块。后续改动沿用这一决策，不恢复定价模块。
- **项目更名 claude-proxy → api-proxy**（f358c8b），当时 Go module 为 `github.com/BenedictKing/api-proxy`；v3.3.14 后使用 `github.com/insistanan/api-proxy`
- 删除 diagrams/ 约 7.6 万行过时产物（75be695），架构图此后以 docs/ 内 Mermaid 为准

## 历史事故与教训（已固化为防御规则）

- 嵌套 dist（`**/backend-go/backend-go/`、`**/frontend/backend-go/`）曾导致构建事故。现在由 `.gitignore` 排除错误目录，门禁中的 `copy-frontend.mjs --check` 也会检查这类问题。
- `.gitignore` 中的 `skills/` 曾误忽略 `backend-go/internal/admin/skills` Go 包，导致 CI 失败。规则已改为仅匹配根目录的 `/skills/`，并保留原因说明。
- 性能画像日志曾让人误以为评分参与选渠。R6 修正了相关日志，并明确画像仅用于观测。
