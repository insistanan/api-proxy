# 历史说明

版本时间与功能变更以 [CHANGELOG.md](../CHANGELOG.md) 为准。v1.x 使用 TypeScript，v2.0.0 起改用 Go；v3.3.0 起由 claude-proxy 更名为 api-proxy。

这里只保留理解当前代码所需的设计动机。

| 决策 | 原因 |
|---|---|
| 单二进制与内嵌管理台 | 减少部署组件，用一个端口交付代理与管理界面 |
| RunProxyRequest 统一编排 | 避免不同协议重复维护选渠、重试、安全处理和日志 |
| 按物理凭据共享准入 | 多个逻辑渠道可能共用同一 URL / 协议 / Key，独立计数会叠加并发 |
| 移除网关计费统计 | 无法获取可信扣费凭证；保留 Token、调用次数、延迟与速率观测 |
| 可逆脱敏与流式还原 | 请求隐藏敏感值，响应还原引用，使客户端仍能使用原始内容 |

过去踩过的坑已进入门禁或规范：

- 错误相对路径产生嵌套前端产物：统一用 copy-frontend.mjs，门禁拒绝嵌套目录。
- 泛化的 skills 忽略规则吞掉后端源码：根运行目录用 `/skills/`，门禁检查未跟踪后端文件。
- 误把性能画像作为路由依据：画像只供展示，选渠遵循配置顺序、健康过滤与组内促销。

当前目录和约束见 [架构说明](架构说明.md)、[规范与不变量](规范与不变量.md)，这里不重复维护实现清单。
