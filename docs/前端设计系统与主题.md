# 前端设计系统与主题

在管理台顶栏点击主题按钮，可以查看当前色板和明暗状态，并打开外观面板。面板可预览并一键应用预设，也可分别调整色板、明暗模式、卡片质感、圆角和背景装饰。**设置 → 外观**提供同一套选项，修改后立即生效，由当前浏览器保存和同步。日夜偏好可设为「跟随系统」，换预设时会保留这一选择。「恢复默认外观」只重置主题。界面交互音效也在此外观面板开关。

| 预设 | 主题色 | 卡片质感 | 圆角 | 背景 |
| --- | --- | --- | --- | --- |
| 跃色 | 莓紫 × 青柠 | 描边撞色、错位硬阴影 | 圆润 | 几何彩点 |
| 清岚 | 青蓝 | 柔和、雾白表面 | 标准 | 纯色 |
| 砚墨（默认） | 靛紫 | 柔和 | 标准 | 纯色 |
| 海浪 | 海蓝 | 扁平 | 标准 | 波浪 |
| 森林 | 森林绿 | 柔和 | 圆润 | 纯色 |
| 落日 | 暖橙 | 厚重 | 圆润 | 波浪 |
| 流光玻璃 | 靛紫 | 玻璃，92% 不透明度 | 圆润 | 光晕 |
| 方正工作台 | 玫瑰 | 厚重 | 方角 | 纯色 |

八套预设都可以使用亮色、暗色和系统模式。跃色偏鲜艳大胆，清岚偏稳重清爽；两套都有独立的暗色配色。主题色、卡片质感、圆角、背景装饰可以独立组合。各主题卡片都有轻量磨砂：跃色保留撞色描边，清岚和方正工作台透明度更低，海浪和落日透光更明显。玻璃卡片另有 85%、92%、100% 三档不透明度，菜单和弹窗使用独立的高不透明度磨砂表面。当前组合与所有预设都不一致时，面板显示「自定义」。预设缩略图使用对应色板和当前明暗模式，不继承正在使用的其他色板。

## 文件放在哪里

| 目录 | 职责 |
| --- | --- |
| `frontend/src/app/layout/` | 应用顶栏、导航和版本入口 |
| `frontend/src/features/` | 渠道、设置、日志等业务的视图、组件、服务和专属布局 |
| `frontend/src/shared/ui/` | Button、Card、Select、Dialog、DataTable 等基础控件 |
| `frontend/src/shared/components/` | 跨业务的组合组件，按 layout、overlay、feedback、data、domain 归档 |
| `frontend/src/shared/theme/` | 主题选项、预设、状态、持久化、外观面板和图表适配 |
| `frontend/src/styles/` | Tailwind 入口、页面基础规则、字体声明及主题变量 |
| `frontend/public/` | 固定 URL 资源，目前是 favicon 与本地字体文件 |
| `frontend/src/api/`、`frontend/src/types/` | 业务 API 聚合入口、前后端契约 |

组件只在一个业务内复用时，留在对应 feature。跨业务复用的组合组件放到 `shared/components/`，例如对话框外壳、JSON 查看器和渠道选择器。基础控件采用与 shadcn-vue 相近的源码维护方式，外观由项目内组件和 Tailwind 管理，复杂交互复用 Reka UI。依赖方向是 `app → features → shared`。新增需要 Vite 处理的资源可放入 `src/assets/`。MDI 图标统一在 `shared/ui/icon/icons.ts` 注册。

## 样式与令牌

`main.ts` 导入 `styles/index.css`。这个入口加载 Tailwind CSS 4、字体、主题和基础样式，并通过 `@theme inline` 把 CSS 变量映射成 Tailwind 类。

| 文件 | 控制内容 |
| --- | --- |
| `styles/theme/tokens.css` | 亮暗基础色、状态色、字体、动效缓动及图表令牌 |
| `styles/theme/palettes.css` | 七种色板的亮暗主色、背景染色和图表系列色 |
| `styles/theme/surfaces.css` | 卡片的边框、阴影、模糊和玻璃不透明度 |
| `styles/theme/radius.css` | 控件、卡片、弹窗和徽标的圆角 |
| `styles/theme/decorations.css` | 波浪、光晕等页面背景装饰 |

页面布局、间距和断点直接使用 Tailwind。文本与表面引用语义类，例如 `text-muted-foreground`、`bg-popover`、`rounded-control`。通用面板使用 `shared/ui/card/Card.vue`，定制容器可以用 `panel-surface` 统一取得卡片圆角、边框、阴影和模糊。主题色用于操作和强调，成功、警告、错误和提示使用独立令牌。圆形进度和图表标记保留功能所需的形状。

输入、文本域、下拉框和文件选择使用 `field-surface` 统一悬停、聚焦、错误和禁用外观。表格、筛选栏、分页、设置侧栏与弹窗共享语义表面和紧凑间距，避免重复包裹卡片造成双重边框。

渠道活跃度图按色板调整造型：跃色使用彩棒与几何端点、斜纹指标条，清岚使用柔和胶囊，海浪使用水纹底线，森林使用叶芽端点和分段指标条，落日使用暖色光带；玻璃质感增加细描边，方角组合使用网格与刻度。时间位置、请求高度、成功率与缓存比例始终来自原数据，绿色、暖色仍分别表达成功与失败风险，不用随机粒子替代数据。

跃色卡片使用边缘撞色，清岚使用轻染色；悬停、聚焦和正在处理请求时提供对应反馈。装饰背景使用有限轮次的漂浮、潮汐与光晕，指标条只在交互或有并发请求时短暂播放。页面切换沿用普通滚动位置，只调整入场动画。所有运动遵循 `prefers-reduced-motion`，减少动态效果时保留静态纹理与数据，不播放动画。

磨砂只在外层面板和浮层采样，嵌套卡片不叠加背景滤镜，主题缩略图只模拟透明表面。弹窗遮罩不对整个视口做模糊，光晕使用径向渐变。窄屏和减少动态效果时降低模糊半径；减少透明效果或不支持背景滤镜时使用不透明表面。活跃度端点仅在跃色、森林创建，森林摇摆只作用于最新数据点；指标快照未变化时复用引用。模型候选按当前连接缓存成功结果，失败可重试，探测最多四路并发，连接变更和关闭表单后忽略旧结果。

顶栏使用可随主题换色的 SVG「AP」标识与 API/Proxy 字标。渠道协议、运行观测、客户端、扩展分别使用独立底色的容器；选中入口用实色与底部标记区分，设置和外观按钮也有对应状态。鼠标速度影响短暂倾斜、扭转与高光，跃色幅度较大，清岚与方正组合更克制；减少动态效果时关闭这些运动。交互由顶栏统一委托，单帧只更新当前元素，离开后取消任务；顶栏高度通过 ResizeObserver 同步给各页吸顶布局。

界面交互音效可在顶栏主题按钮打开的外观面板中开关，偏好保存在当前浏览器。音效使用 Web Audio 短音，不下载音频文件；首次点击顶栏控件或按键激活后才创建音频上下文，悬停不主动解锁播放。主题、划过速度和点击动作影响音色与音高，连续悬停最多每 110 毫秒播放一次。后台暂停音频，关闭音效后不再播放；组件卸载时关闭上下文，实际播放错误会提示并关闭音效。该开关只控制顶栏音效，不影响危险命令通知。

Tailwind 需要在源码中扫描到完整类名。可按状态选择完整的类，如 `active ? 'bg-primary/10' : 'bg-card'`。业务特有的容器查询、第三方选择器以及需要组合的样式留在相关模块。组件样式可用 `@reference` 引用 Tailwind 入口后使用 `@apply`，运行时的图表颜色、宽度和位移可以通过变量或组件参数传入。

## 如何扩展

1. **新增预设**时，在 `shared/theme/catalog.ts` 的 `THEME_PRESETS` 添加名称、ID 和组合。预览从同一套 CSS 令牌生成。
2. **新增色板**时，在 `shared/theme/types.ts` 添加色板 ID，在 `catalog.ts` 的 `THEME_OPTIONS` 登记名称，再在 `palettes.css` 定义亮暗两套变量。现有控件和图表会通过语义令牌取色。
3. **新增质感、圆角或装饰**时，同步类型、选项目录和对应的主题 CSS。背景元素由 `shared/theme/components/ThemeBackground.vue` 渲染。
4. **新增基础组件**时，放在 `shared/ui/` 对应类别中，在组件内维护变体。弹窗、菜单、下拉框等优先复用现有控件，继承焦点、键盘和浮层行为。

运行时在 Vue 挂载前读取 `api-proxy-theme`，把当前模式和外观选项写到 `html` 的 `data-*` 属性，传送到 `body` 的浮层也会继承主题。首次升级时会迁移 `api-proxy-preferences.darkModePreference`，将旧的 `auto` 对应到 `system`，并保留其他偏好。读取、迁移或写入失败时，外观面板会显示原因。主题遵循浏览器的本地存储范围。

图表在 `shared/theme/charts.ts` 统一读取 CSS 令牌。新增 ApexCharts 图表时，用 `useChartColors()` 配置系列、网格、文字和提示框颜色，以便响应主题变化。

## 验证

在 `frontend/` 执行以下命令检查类型、图标、代码规范、测试和生产构建。

```sh
npm run check
npm run lint -- --max-warnings 0
npm test
npm run build
```

外观改动应在浏览器检查亮暗模式、窄屏布局、键盘操作和玻璃表面的可读性。浏览器兼容范围参考 [Tailwind CSS 兼容性说明](https://tailwindcss.com/docs/compatibility)。组件与样式机制可查阅 [Reka UI 文档](https://reka-ui.com/docs/overview/introduction)、[shadcn-vue 主题文档](https://www.shadcn-vue.com/docs/theming) 和 [Tailwind 主题变量](https://tailwindcss.com/docs/theme)。
